# Clawd 이미지 에셋 출처

Claude Code 마스코트 **Clawd**(픽셀 게) 이미지 모음. 교육 가이드북 디자인용.

## 수집 현황

| 폴더 | 수량 | 형식 | 내용 |
|---|---|---|---|
| `emotes/` | 24 | GIF (애니메이션, 투명배경) | 코딩·커피·수면·독서·기타 연주 등 일상 이모트 + 명절 시리즈 |
| `poses/` | 16 | PNG (투명배경) | 정면/측면/후면, 매달리기·엿보기·안기·기어오르기 등 정지 포즈 |
| `demo/` | 3 | PNG (고해상도) | 실사 배경 합성 예시 (노트북 엿보기, 케이블 안기, Mac mini 위 수면) |
