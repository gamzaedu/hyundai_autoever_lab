1. 스킬 완성 — 채워야 할 4곳

위치채울 내용💀 실패 신호

📏 description 공식 <무엇을 한다>. <트리거 단어들>이(가) 나올 때 사용한다.
예시 
신규 서비스 기획 요청을 PRD 문서로 작성한다.
"PRD", "기획서", "요구사항 정리", "브리프를 문서로" 같은 요청이 있을 때 사용한다.

2. PRD 생성 — 스킬 이름을 부르지 않는다

새 세션에서

LV.6 · 6교시

나만의 훅

합격 조건은 코드가 아니라 발동 장면의 재현이다.

⏱️ 10분 🎯 트랙 택 1 ✅ 발동 장면 재현 🎁 획득 : 🪝 Hook

🗺️ 미션

🗂️ 트랙 택 1

트랙이벤트채울 것발동 방법
🛡️ A 가드레일
A_guard.js		PreToolUse BASH_DENY 패턴 2개↑ · PATH_DENY 패턴 1개↑ · Read/Edit/Write 경로 검사 로직 금지 명령을 일부러 요청 → 차단 메시지 확인
📊 B 통계
B_stats.js		SessionEnd rec.type 으로 user/assistant 발화 수 집계 · tool_use 블록 도구별 카운트 · 마크다운 표 조립 세션 종료(/clear) → 리포트 파일 확인
📓 C 작업일지
C_worklog.js		Stop changedFiles() 에서 Edit/Write 의 file_path 수집 · 헤더 생성 · 시각 / 변경 파일 append 아무 파일이나 수정 요청 → worklog.md 확인

_stdin.js 는 완성본이다. 손대지 않아도 되지만 같은 폴더에 반드시 함께 둔다.

📁 배치

프로젝트 구조
<프로젝트>/
└─ .claude/
   ├─ settings.json
   └─ hooks/
      ├─ _stdin.js
      └─ <선택한 파일>.js

⚙️ 등록 — settings.json

트랙 A · PreToolUse 
{
  "hooks": {
    "PreToolUse": [
      { "matcher": "Bash|Read|Edit|Write",
        "hooks": [{ "type": "command", "command": "node .claude/hooks/A_guard.js" }] }
    ]
  }
}
트랙 B · SessionEnd 
{
  "hooks": {
    "SessionEnd": [
      { "hooks": [{ "type": "command", "command": "node .claude/hooks/B_stats.js" }] }
    ]
  }
}
트랙 C · Stop 
{
  "hooks": {
    "Stop": [
      { "hooks": [{ "type": "command", "command": "node .claude/hooks/C_worklog.js" }] }
    ]
  }
}
🧪 등록 없이 먼저 테스트하기 — 이 방법이 가장 빠르다 세션에 붙였다 뗐다 하지 말고, 가짜 입력으로 스크립트만 먼저 돌려 맞춘다.
단독 실행 
echo '{"tool_name":"Bash","tool_input":{"command":"rm -rf ./dist"},"cwd":"."}' | node .claude/hooks/A_guard.js
echo $?
기대값
차단exit 2 + stderr 메시지
통과exit 0
