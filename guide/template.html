1. 스킬 구조 — SKILL.md 한 장이면 된다

구성내용💀 실패 신호

출력 형식 · 규칙결과물 형식 고정 + 하지 말 것모호어("깔끔하게") 사용
reference (선택)길어지는 예시 · 표는 별도 파일로 분리본문이 수백 줄 → 매번 다 읽힘

<프로젝트>/
└─ .claude/

"PRD", "기획서", "요구사항 정리", "브리프를 문서로" 같은 요청이 있을 때 사용한다.

라이선스사내 배포 가능한 범위인지 (예 caveman 은 skills/ 만 MIT)

✏️ 사내 규격 · 설계 리뷰 기준을 스킬로 만들면 그대로 자산이 된다

3. 무엇을 만들까 — grill-me 에게 정하게 한다

주제 발굴 
/grill-me

어떤 걸 스킬로 만들면 좋을지 정하는 것부터 도와줘.

좋은 후보 — 매번 형식이 같은 산출물(회의록 · 장애보고 · 코드리뷰 코멘트 · 릴리즈 노트) · 매번 같은 말을 반복하는 지시(우리 팀 컨벤션으로 고쳐줘).

4. 초안을 skill-creator 로 개선

LV.6 · 6교시

나만의 훅

필요한 규칙을 코드로 강제한다. 합격 조건은 코드가 아니라 발동 장면의 재현이다.

🗺️ 미션

🗂️ 참고 예시 3종 — 그대로 써도, 갈아엎어도 된다

예시이벤트채울 것발동 방법
🛡️ A 가드레일
A_guard.js		PreToolUse BASH_DENY 패턴 2개↑ · PATH_DENY 패턴 1개↑ · Read/Edit/Write 경로 검사 로직 강사 시연 예시 — .env 를 읽어달라고 요청 → 차단 메시지 확인
📊 B 통계
B_stats.js		SessionEnd rec.type 으로 user/assistant 발화 수 집계 · tool_use 블록 도구별 카운트 · 마크다운 표 조립 세션 종료(/clear) → 리포트 파일 확인
📓 C 작업일지
C_worklog.js		Stop changedFiles() 에서 Edit/Write 의 file_path 수집 · 헤더 생성 · 시각 / 변경 파일 append 아무 파일이나 수정 요청 → worklog.md 확인

_stdin.js 는 완성본이다. 손대지 않아도 되지만 같은 폴더에 반드시 함께 둔다.

🧭 무엇을 훅으로 막을까 — 내 훅을 설계하는 질문
  • Claude 에게 절대 보여주면 안 되는 파일이 우리 레포에 있는가? (.env · 키 · 고객데이터)
  • 매번 말로 부탁하지만 가끔 안 지켜지는 규칙은? (커밋 금지 · 특정 폴더 수정 금지)
  • 작업이 끝날 때마다 사람이 손으로 하던 일은? (린트 · 테스트 · 일지 기록)
훅 설계 요청 
A_guard.js 를 참고해서, 우리 팀에 필요한 훅을 하나 만들려고 해.
차단할 명령어와 차단할 파일 경로를 먼저 추천해줘.

위 내용으로 예시 완성 훅을 작성해줘.

📁 배치

프로젝트 구조
<프로젝트>/
└─ .claude/
   ├─ settings.json
   └─ hooks/
      ├─ _stdin.js
      └─ <선택한 파일>.js

⚙️ 등록 — settings.json

트랙 A · PreToolUse 
{
  "hooks": {
    "PreToolUse": [
      { "matcher": "Bash|Read|Edit|Write",
        "hooks": [{ "type": "command", "command": "node .claude/hooks/A_guard.js" }] }
    ]
  }
}
트랙 B · SessionEnd 
{
  "hooks": {
    "SessionEnd": [
      { "hooks": [{ "type": "command", "command": "node .claude/hooks/B_stats.js" }] }
    ]
  }
}
트랙 C · Stop 
{
  "hooks": {
    "Stop": [
      { "hooks": [{ "type": "command", "command": "node .claude/hooks/C_worklog.js" }] }
    ]
  }
}
🧪 등록 없이 먼저 테스트하기 — 이 방법이 가장 빠르다 세션에 붙였다 뗐다 하지 말고, 가짜 입력으로 스크립트만 먼저 돌려 맞춘다.
단독 실행 
echo '{"tool_name":"Bash","tool_input":{"command":"rm -rf ./dist"},"cwd":"."}' | node .claude/hooks/A_guard.js
echo $?

echo '{"tool_name":"Read","tool_input":{"file_path":".env"},"cwd":"."}' | node .claude/hooks/A_guard.js
echo $?
기대값
차단exit 2 + stderr 메시지
통과exit 0

⬜ 를 채우기 전에는 .env 예시도 exit 0 이 나온다 — PATH_DENY 와 경로 검사 로직을 채워야 2 로 바뀐다. 그 변화가 이 실습의 확인 지점이다.
