# CLAUDE.md


## 답변 원칙

- 모든 응답은 **개조식 + 명사형 종결**로 작성합니다.
- 조사·서술어를 최소화하고 핵심 명사구로 끊습니다.
  - 예: "SPEC을 구성했습니다" → "SPEC 구성 완료"
  - 예: "테스트를 실행했으나 3건이 실패했습니다" → "테스트 실행 / 3건 실패"
- 직관적으로 표현하기 위해, 표 형식을 적극적으로 사용합니다. 
- 단, 오류 원인 설명·트레이드오프 논의 등 맥락이 필요한 부분은 서술식 허용.

## 프로젝트 개요

- 서비스명 : Fleet Console — 법인 차량 관제 콘솔
- 목적 : `as_of` 기준 차량 스냅샷 조회 · 알람(AL-01~03) 판정 · 단일 화면 관제

---

## 기술 스택 및 코딩 컨벤션

- 기술 스택
  - FE : React 18 + Vite 5 + TypeScript 5.6
  - BE / DB : 없음 — `public/data/*.json` 정적 로드
- 코딩 컨벤션
  - 컴포넌트 파일 `PascalCase.tsx` · 유틸 파일 `camelCase.ts`
  - 상수는 `UPPER_SNAKE_CASE`, 선언 위치는 `lib/`
  - 타입 선언은 `types.ts` 에만 작성
  - 주석은 "왜"만 기술, "무엇"은 금지

---

## 개발 원칙

- 디자인이 필요한 작업은 같은 디렉토리의 `DESIGN.md` 파일을 확인하여 작업합니다. 
  - ex) FE UI 작업 
- 코드 작업이 완료되면, 실행 bat 스크립트를 제작합니다.
  - window 환경으로 가정하고 CRLF 에 유의하여 작성합니다.
