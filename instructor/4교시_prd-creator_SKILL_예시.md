# PRD Creator

기획 요청 원문(브리프, 메일, 회의록)을 개발팀이 바로 착수 가능한 PRD 로 변환한다.

## 실행 절차

1. 브리프를 읽고 **확인된 사실** 과 **요청자의 희망사항** 을 분리한다.
2. 브리프에 없는 항목을 찾는다 → 사실로 도출 가능하면 본문에 확정 기재, 불가하면 `미결정 사항` 으로 뺀다.
3. 아래 `출력 형식` 목차 순서 그대로 작성한다.

## 규칙

- 브리프에 없는 수치·정책을 추측해서 단정하지 않는다 → `미결정 사항` 에 사유와 함께 남긴다.
- 모호어("적절히", "빠르게", "깔끔하게")를 쓰지 않는다 → 수치 또는 판정 조건으로 바꾼다.
- 목차 7개 섹션은 고정한다. 내용이 없어도 "해당 없음" 으로 남긴다.
