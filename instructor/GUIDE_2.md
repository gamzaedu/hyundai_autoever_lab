### B2-2 · 핵심 명령어 6종 (10:35~10:50 · 15분)

**목표** — 6개 명령어를 **실황으로** 보여준다. 목록을 읽어주지 않는다.

**판서 — 먼저 6개를 적어두고 하나씩 지워가며 시연**

```
/rewind    되돌리기          ← Git 대신
/compact   요약해서 압축
/clear     싹 비우기
/resume    이전 세션 이어받기
/context   지금 얼마나 찼나
/status    지금 어떤 상태인가
```

#### LAB_2-1 · 타임머신 — `/rewind` (5분)

> "1교시에 제가 차량 5대 JSON 만들었죠. 그걸로 시작하겠습니다.
>
> 이제 제가 **일부러 잘못된 지시** 를 내리겠습니다. 실무에서 자주 하는 실수예요."

**입력 프롬프트 (의도적 붕괴)**

```
이 JSON 구조를 전부 갈아엎어줘. 배열 대신 객체로 바꾸고,
필드 이름도 전부 축약형으로 바꾸고, 부서 정보는 빼줘.
```

> "(실행 후 파일 열기)
>
> 자, 망가졌습니다. 필드명이 `vn`, `bt` 이런 식으로 바뀌었고 부서가 사라졌습니다.
>
> 여기서 여러분이 실무에서 하는 행동이 뭐냐면요. **'아 아니야, 원래대로 돌려줘'** 라고 말하는 겁니다.
>
> 그러면 어떻게 될까요? AI가 **기억으로 복원을 시도합니다.** 원본이랑 미묘하게 다른 게 나옵니다. 그리고 그걸 또 고치라고 하고, 점점 산으로 갑니다.
>
> 정답은 이겁니다."

**입력**

```
/rewind
```

> "보세요. **대화 시점 목록** 이 나옵니다. 제가 잘못된 지시를 내리기 **직전** 으로 가겠습니다.
>
> (선택 후) 파일 확인해보겠습니다. **원래대로 돌아왔습니다.**
>
> 이게 왜 중요하냐면요. 오늘 우리는 **Git을 안 씁니다.** 그런데 되돌릴 수단은 필요하죠.
>
> `/rewind` 가 그 역할을 합니다. **대화와 파일 상태를 함께 되감습니다.**
>
> 오늘 실습 중에 뭔가 크게 망가지면, 처음부터 다시 하지 마시고 `/rewind` 부터 떠올리세요."

> **주의** — `/rewind` 의 복원 범위는 버전에 따라 다르다. **교육 전 강사 PC에서 반드시 리허설할 것.** 파일까지 되돌아가지 않는 버전이라면 "대화만 되감고 파일은 다시 지시" 로 대사를 수정한다.

#### LAB_2-2 · 컨텍스트 다이어트 — `/compact` vs `/clear` (6분)

> "다음. 아까 컨텍스트가 찬다고 했죠. 실제로 채워보겠습니다.
>
> 먼저 지금 상태 확인하겠습니다. `/context`
>
> (수치 확인) 지금 이 정도 찼습니다. 기억해두세요.
>
> 이제 제가 주행 이력 데이터를 읽히겠습니다. 1,100줄짜리입니다."

**입력**

```
module_2/data/trips.json 을 읽고, 부서별 주행거리 합계를 계산해줘.
```

> "(완료 후) 다시 `/context` 보겠습니다.
>
> **확 늘었죠.** 파일 하나 읽었을 뿐인데요.
>
> 그런데 생각해보세요. 저는 **합계 숫자만** 필요합니다. 1,100줄 원본은 이제 필요 없어요. 그런데 계속 자리를 차지하고 있습니다.
>
> 이럴 때 쓰는 게 두 개입니다."

**판서**

```
/compact   대화를 요약본으로 압축     결론은 남고, 원본은 버림
/clear     대화를 통째로 삭제         전부 사라짐

           "정리"                     "리셋"
```

> "`/compact` 를 써보겠습니다."

**입력**

```
/compact
```

> "(완료 후) `/context` 다시 보겠습니다. **줄었죠.**
>
> 그런데 중요한 건, 방금 계산한 부서별 합계는 **기억하고 있습니다.** 확인해볼까요?"

**입력 (확인용)**

```
방금 계산한 부서별 주행거리 합계 중 1위가 어디였지?
```

> "답합니다. **결론은 남기고 원본만 버린 겁니다.**
>
> `/clear` 는 다릅니다. 이건 전부 날립니다. 새 작업으로 완전히 넘어갈 때만 쓰세요.
>
> 판단 기준은 간단합니다."

**판서**

```
같은 작업 계속함  →  /compact
완전히 다른 작업  →  /clear
```

#### LAB_2-3 · 세션 이어받기 — `/resume` (3분)

> 잘 정리된 세션 하나가, 매번 처음부터 설명하는 것보다 훨씬 낫습니다.
