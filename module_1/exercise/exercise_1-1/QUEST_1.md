## 💡 아이디어 (택 1)

| # | 아이디어 | 핵심 기능 |
| --- | --- | --- |
| 1️⃣ | 나만의 사원증 카드 | 프로필 입력 → 카드 렌더링 → 인쇄/이미지 저장 |
| 2️⃣ | 신입사원 모여모여 커뮤니티 | 게시글 작성 · 목록 · 상세 · 삭제 |
| 3️⃣ | 우리 기수 명함첩 | 동기 등록 · 검색 · 태그 필터 |
| 4️⃣ | 온보딩 체크리스트 트래커 | 항목 체크 · 진척률 게이지 · 저장 |
| 5️⃣ | 오늘의 TIL 로그 | 날짜별 기록 작성 · 조회 · 검색 |
| 6️⃣ | 점심 메뉴 정하기 | 후보 등록 · 투표 · 집계 |

> 💬 위 목록에 없는 아이디어도 환영. 단, **저장 → 조회** 흐름이 있을 것.

## 🧰 스택 선택

- React · Vue · Next.js · FastAPI · Flask · Express · Streamlit … **무엇이든 가능**
- 스택 선정 자체를 Claude 에게 맡겨도 무방

```
나는 풀스텍 엔지니어로 웹 프로그래밍 기술스택에 익숙해. 가벼운 웹 프로젝트에 적합한 스택을 추천하고 그 이유를 알려줘.
```

## ✅ 성공 기준 (3종 모두)

| # | 기준 | 확인 방법 |
| --- | --- | --- |
| 🚀 실행 | 서버/앱 정상 기동, 브라우저 접속 성공 | 실제 화면 확인 |
