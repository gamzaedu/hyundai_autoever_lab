# PRD — 커넥티드카 관제 콘솔 (Fleet Monitoring Console) v1.0

| 항목 | 내용 |
| --- | --- |
| 문서 버전 | v1.0 |
| 작성 조직 | 커넥티드카개발팀 |
| 대상 시스템 | 사내 업무차량 통합 관제 웹 콘솔 |
| 개발 기간 | **20분** (타임어택) |
| 만점 / 통과선 | **100점 / 65점** |

---

## 1. 배경 및 목적

사내 업무차량 30대가 각기 다른 담당부서에 흩어져 운영 중이며, 현재는 차량 상태를 부서별 엑셀로 관리하고 있음. 배터리 방전·통신 두절·정비 누락이 사후에야 발견되어 운행 차질이 반복되고 있음.

본 콘솔은 **전 차량의 상태를 한 화면에서 확인하고, 조치가 필요한 차량을 즉시 식별**하는 것을 목적으로 함.

## 3. 데이터 명세

### 3.1 제공 파일 (`module_2/data/`)

| 파일 | 내용 |
| --- | --- |
| `vehicles.json` | 차량 30대 스냅샷 + 기준시각 `as_of` |
| `trips.json` | 차량별 최근 주행 이력 5건 |
| `alarm_cases.json` | ❌ **자가채점 전용 정답지** — 구현 코드에서 참조 시 데이터 정확성 0점 |

### 3.2 차량 필드

| 필드 | 타입 | 비고 |
| --- | --- | --- |
| `vehicle_id` | string | `VH-0001` 형식 |
| `plate` | string | 차량번호 |
| `model` / `powertrain` | string | `EV` / `HEV` / `ICE` |
| `status` | enum | `DRIVING` · `IDLE` · `MAINTENANCE` · `OFFLINE` — **`last_seen` 시점에 마지막으로 수신된 상태값** (현재 상태 아님) |
| `soc_pct` | number \| **null** | `ICE` 차량은 `null` |
| `fuel_pct` | number \| null | `EV` 차량은 `null` |
| `odometer_km` | number | 누적 주행거리 |
| `last_seen` | ISO8601 | 최근 통신 시각 |
| `location` | object | `name` · `lat` · `lng` |
| `owner_dept` | string | 담당 부서 |
| `dtc_codes` | string[] | 진단 코드, 없으면 `[]` |

> **현재 시각은 시스템 시각이 아니라 `vehicles.json` 의 `as_of` 값을 사용할 것.** (재현 가능한 채점을 위함)

### 3.3 주행 이력 필드 (`trips.json`)

| 필드 | 타입 | 비고 |
| --- | --- | --- |
| `started_at` / `ended_at` | ISO8601 | 최근순 정렬 상태로 제공 |
| `distance_km` / `avg_speed_kph` | number | 주행거리 · 평균속도 |
| `energy_kwh` | number? | `EV` · `HEV` 만 존재 |
| `fuel_l` | number? | `ICE` · `HEV` 만 존재 |

> 파워트레인에 따라 존재하는 필드가 다름 — 상세 패널은 **없는 필드를 `undefined` 로 표기하지 말 것**

## 5. 알람 판정 규칙 핵심

| ID | 규칙 | 조건 | 심각도 |
| --- | --- | --- | --- |
| **AL-01** | 배터리 부족 | `powertrain == "EV"` **AND** `soc_pct < 15` | 🔴 CRITICAL |
| **AL-02** | 정비 필요 | `status == "MAINTENANCE"` **OR** `dtc_codes` 가 1건 이상 | 🟡 WARNING |
| **AL-03** | 통신 두절 | `as_of - last_seen > 30분` | 🔴 CRITICAL |

### 판정 시 유의사항

- **경계값은 미포함** — `soc_pct == 15.0` 은 AL-01 아님, 무신호 `정확히 30분` 은 AL-03 아님
- **`soc_pct` 가 `null` 인 ICE 차량은 AL-01 대상 아님** (연료량으로 대체 판정하지 않음)
- 한 차량이 **복수 알람**을 가질 수 있음
- **KPI 의 "알람 차량 수" 는 차량 기준 중복 제거**, FR-09 의 알람 이력은 **알람 건 단위**로 집계
