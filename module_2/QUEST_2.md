## 함정 주의보

| 함정 | 내용 |
| --- | --- |
| 시각 | 현재 시각은 **시스템 시각이 아니라 `as_of`** 값 |
| 경계값 | `SOC == 15.0` 은 알람 ❌ / 무신호 `정확히 30분` 은 알람 ❌ |
| null | `ICE` 차량은 `soc_pct` 가 `null` → 배터리 알람 대상 ❌ |
| 중복 | KPI 알람 수 = **차량 기준 중복제거** / 알람 센터 = **건 단위** |
| 복수 | 한 차량이 알람 2개 이상을 동시에 가질 수 있음 |
| KPI 연동 | KPI 는 **전체가 아니라 필터 결과** 기준 |
| 가동률 | 분모는 **부서 전체 대수** (운행중 차량만이 아님) |
| 부서 평균 SOC | **EV 차량만** 평균 — ICE·HEV 섞으면 오답 |
| ACK | 모든 알람을 확인한 차량은 **KPI 알람 수에서 빠짐** |
| HEV | `energy_kwh` · `fuel_l` **둘 다 존재** → 전비·연비 둘 다 표기 |
| 지속성 | ACK·정비 큐는 **새로고침 후에도 유지** (NFR-05) |

> 데이터 정확성 10점은 **전부 이 함정에서 갈림**
