## 🔴 CR-01 — 알람 임계값 정책 변경

| 구분 | AS-IS | TO-BE |
| --- | --- | --- |
| AL-01 배터리 부족 | SOC **15%** 미만 | SOC **20%** 미만 |
| AL-03 통신 두절 | 무신호 **30분** 초과 | 무신호 **15분** 초과 |

### 요구사항

- ✅ 임계값 변경이 **알람 판정 · 목록 강조 · 상세 패널 전부에 동일하게** 반영될 것
- ✅ 임계값은 **단일 지점에서만 정의**될 것 (다음 정책 변경 시 한 곳만 고치면 되도록)
- ✅ 기존 기능은 그대로 동작할 것

### ✅ 검증 방법

| 확인 | 기대 결과 |
| --- | --- |
| 알람 차량 수 KPI | 10대 → **12대** (총 알람 12건 → **14건**) |
| `VH-0013` (SOC 15.0%) | v1.0 에선 정상 → v1.1 에서 **AL-01 발생** |
| `VH-0018` (무신호 30분) | v1.0 에선 정상 → v1.1 에서 **AL-03 발생** |
| 목록 강조 ↔ 알람 배지 | 두 표시가 **항상 같은 차량**에 붙을 것 (기준 불일치 금지) |
| 임계값 정의 위치 | SOC·무신호 임계값이 **각각 단일 지점**에만 존재 |

> 💀 **2교시의 경계값 함정 2대가 정책 변경으로 뒤집힘.** 임계값이 흩어져 있으면 이 2대가 화면마다 다르게 보임.

## 🟡 CR-02 — 상태 라벨 한글화 + `충전중` 상태 신설

### 요구사항

- ✅ 데이터 소스를 `public/data/vehicles_v11.json` 로 교체
- ✅ 신규 상태 `CHARGING` 지원 (기존 4종 → **5종**)
- ✅ 화면에 노출되는 상태는 **모두 한글**로 표기

| 코드값 | 표시 라벨 |
| --- | --- |
| `DRIVING` | 운행중 |
| `IDLE` | 정차 |
| `CHARGING` | **충전중** |
| `MAINTENANCE` | 정비필요 |
| `OFFLINE` | 오프라인 |

- ⚠️ **KPI '운행중' 카드에 `충전중` 을 포함하지 말 것** (별도 카드 추가도 하지 말 것)
- ✅ 라벨 매핑은 **단일 지점에서만 정의**될 것

### ✅ 검증 방법

| 확인 | 기대 결과 |
| --- | --- |
| 상태 표기 | 목록 · 필터칩 · 상세 패널 **3곳 모두** 한글 |
| 필터 칩 | 5개 (충전중 포함) |
| KPI 운행중 | **17대** (충전중 4대 미포함) |
| 충전중 배지 | 전용 색상 적용, 미지정 스타일 없음 |

## 🟢 CR-03 — '통신 경과' 컬럼 추가

### 요구사항

- ✅ 차량 목록에 **`통신 경과(분)`** 컬럼 추가 (`as_of` 기준 경과 분, 정수)
- ✅ AL-03 임계값 **초과 시 강조 표시** (임계값은 CR-01 에서 정한 단일 지점 참조)
- ✅ 해당 컬럼 **정렬 지원**
- 🚫 시각화 라이브러리 · 차트 도입 금지, **CDN 링크 추가 금지**
- 🚫 요구되지 않은 컬럼 추가 · 기존 컬럼 삭제 금지

### ✅ 검증 방법

| 확인 | 기대 결과 |
| --- | --- |
| 컬럼 값 | `95`, `47`, `210` 등 정수 분 단위 |
| 강조 | 15분 초과 행만 강조 |
| 임계값 | CR-01 상수 재사용, **새 하드코딩 없음** |
| 의존성 | `package.json` 변동 없음, `index.html` 에 외부 링크 없음 |
