# 🔋 요구 브리프 — 사내 EV 충전기 예약 서비스

> 📌 이 문서는 **기획 요청 메일 수준**의 원문이다. PRD 가 아니다.

---

## 📨 요청 원문 (총무팀 → 개발팀)

> 안녕하세요, 총무팀입니다.
>
> 본사 지하주차장 EV 충전기 때문에 민원이 계속 들어옵니다.
> 충전기는 있는데 항상 누가 꽂아놓고 안 빼서, 오후에 오는 직원들은 아예 못 씁니다.
> 완충되고도 몇 시간씩 자리를 차지하는 경우가 많다고 합니다.
>
> 예약해서 쓸 수 있게 시스템을 하나 만들어 주시면 좋겠습니다.
> 사내에서만 쓰는 거라 크게 복잡할 필요는 없고, 다음 달까지 되면 좋겠습니다.
>
> 감사합니다.

## 🏢 확인된 사실 (총무팀 추가 회신)

| 항목 | 내용 |
| --- | --- |
| 🔌 충전기 대수 | 급속 2기 · 완속 6기 (지하 2층) |
| 👥 대상 인원 | 본사 상주 약 900명, 전기차 등록 차량 약 70대 |
| ⏰ 운영 시간 | 24시간 (주차장 개방 시간과 동일) |
| 📊 현재 운영 | 예약 없음, 선착순. 관리대장은 종이 |
| 🔗 연동 가능 여부 | 충전기 제조사 API **연동 불가** (망 정책) |
| 💳 요금 | 사내 복지로 **무료** |

## ❓ 브리프에 없는 것들 (의도적)

이 브리프는 **일부러 비어 있다.** 아래는 예시일 뿐이며, 더 많은 구멍이 있다.

- 노쇼(예약하고 안 옴) 처리 방침
- 완충 후 미이동 차량에 대한 제재 여부
- 예약 단위 시간 · 1인 최대 예약 횟수
- 급속/완속 구분 예약 가능 여부
- 임원·장애인 우선권 존재 여부

> 🎯 **여러분의 과제** : 이 구멍들을 PRD 에서 **결정하거나, 결정할 수 없는 이유를 명시**하는 것.
> 빈칸을 그대로 둔 PRD 는 `grill-me` 에게 그대로 뚫린다.
