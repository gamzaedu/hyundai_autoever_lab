# 🎮 신입사원 퀘스트 5 : 코드리뷰 3인 위원회

> ⏱️ **제한 시간 10분** · 🐛 숨은 결함 **8종** · 🏆 실시간 스코어보드

---

## 🎯 미션

관제 시스템 코드에 **결함 8개**가 숨어 있다.
서브에이전트 **3명**을 병렬로 띄워 찾아내고, **통합 리포트 1장**으로 제출한다.

| 에이전트 | 담당 |
| --- | --- |
| 🔒 security-reviewer | 주입 · 시크릿 · 인증 · 입력검증 |
| ⚡ performance-reviewer | N+1 · 복잡도 · 재계산 · 대기 |
| 📏 convention-reviewer | 네이밍 · 매직넘버 · 데드코드 |

---

## 📦 리뷰 대상

| 파일 | 스택 | 설명 |
| --- | --- | --- |
| `review-target/telemetry_api.py` | 🐍 Python (Flask) | 텔레메트리 조회 백엔드 |
| `review-target/web/` | ⚛️ React + TS | 관제 콘솔 프론트엔드 스냅샷 |

> ⚠️ **이 코드는 실행하지 않는다.** `npm install` · `pip install` 불필요.
> 리뷰 전용 스냅샷이라 빌드가 통과하지 않을 수 있다. **읽고 판단하는 것**이 과제다.

## 1️⃣ 에이전트 배치

강사 제공 정의 파일 3개를 실습 프로젝트에 복사한다.

```
<프로젝트>/.claude/agents/security-reviewer.md
<프로젝트>/.claude/agents/performance-reviewer.md
<프로젝트>/.claude/agents/convention-reviewer.md
```

> 💡 정의 파일을 **직접 손봐도 된다.** 탐지율이 오르면 그것도 실력이다.

---

## 2️⃣ 병렬 리뷰 실행

```
review-target 폴더를 security-reviewer, performance-reviewer, convention-reviewer
3개 서브에이전트로 병렬 리뷰해줘.
각자 자기 범위만 보게 하고, 결과 표를 그대로 보여줘.
```

### ⚠️ 하면 안 되는 것

| ❌ 금지 | 이유 |
| --- | --- |
| 에이전트에게 **코드 수정** 시키기 | 리뷰가 목적. 수정은 범위 밖 |
| 3명에게 **똑같은 지시** 하기 | 시야를 안 나누면 리포트가 겹친다 |
| 순차 실행 | 병렬의 이득(컨텍스트 절약)을 못 본다 |
