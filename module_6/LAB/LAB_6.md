## 📖 이론 (00~10분) — 라이프사이클

| 이벤트 | 언제 | 대표 용도 | 차단 가능 |
| --- | --- | --- | --- |
| `PreToolUse` | 도구 실행 **직전** | 🛡️ 가드레일, 승인 정책 | ✅ |
| `PostToolUse` | 도구 실행 **직후** | 🎨 자동 포맷, 변경 감사 | ⚠️ 사후 |
| `Stop` | 응답이 **끝날 때** | 🧪 테스트, 📓 로그 | ✅ (재작업 유도) |
| `SessionEnd` | 세션 **종료 시** | 📊 통계, 정리 | ❌ |

### 🔢 종료 코드 규약 (핵심)

| exit | 의미 | 동작 |
| --- | --- | --- |
| `0` | 정상 | stdout 은 기록만 됨. 흐름 개입 없음 |
| `2` | **차단/되돌리기** | **stderr 내용이 Claude 에게 전달**됨 → 이어서 작업 |
| 기타 | 훅 자체 오류 | 사용자에게 경고 표시, 흐름은 계속 |

> 💥 **핵심 문장**
> "**exit 2 가 훅의 전부다.** 0 은 지켜보는 것이고, 2 는 개입하는 것이다."

### 🆚 다른 하네스 요소와의 차이

| 요소 | 개입 시점 | 모델 판단 |
| --- | --- | --- |
| 📜 CLAUDE.md | 항상 프롬프트에 존재 | ✅ 모델이 **읽고 판단** |
| 🩺 Skill | 트리거 매칭 시 | ✅ 모델이 **호출 여부 결정** |
| 🎭 SubAgent | 위임 시 | ✅ 모델이 **위임 여부 결정** |
| 🪝 **Hook** | **정해진 이벤트** | ❌ **판단 없음. 무조건 실행** |

> "CLAUDE.md 에 '테스트를 꼭 돌려라' 라고 써도 **안 돌릴 수 있다.**
> 훅에 걸면 **안 돌릴 방법이 없다.**"

## 🧪 LAB_6-2 「회귀테스트 훅」 (10분)

> 🎯 이 LAB 이 6교시의 **하이라이트**다. 반드시 실패 장면을 만든다.

### 🎬 진행

| 단계 | 행동 | 화면 |
| --- | --- | --- |
| 1️⃣ | 대상 레포를 `module_3/fleet-console-base` 로 이동 | — |
| 2️⃣ | `regression.js` 를 `Stop` 훅으로 등록 (`npx tsc -b`) | — |
| 3️⃣ | 정상 상태에서 아무 작업 → `[regression] PASS` | 조용히 통과 |
| 4️⃣ | **일부러 타입 오류를 만들라고 지시** | ⬇️ |
| 5️⃣ | Claude 가 "완료했습니다" 하는 순간 훅이 발동 | 🔴 `FAIL` + 오류 목록 |
| 6️⃣ | Claude 가 **스스로** 오류를 고치고 다시 종료 시도 | ♻️ 자가 수정 루프 |

### 🗣️ 투입 프롬프트 (4단계)

```
src/lib/format.ts 맨 아래에 아래 줄을 그대로 추가해줘.
const __broken: number = "문자열"
```

### ✅ 검증된 동작 (사전 테스트 완료)

| 상황 | exit | 결과 |
| --- | --- | --- |
| 타입체크 통과 | `0` | `[regression] PASS` |
| 타입체크 실패 | `2` | `FAIL` + `error TS2322 ...` 가 Claude 에게 전달 |
| 훅 때문에 재개된 세션 | `0` | `skip (stop_hook_active)` — 무한루프 차단 |

### ⚠️ 반드시 짚을 것 — 무한루프

```js
if (input.stop_hook_active) { process.exit(0) }
```

> "이 3줄이 없으면 **훅이 훅을 부르는 무한루프**에 빠진다.
> `Stop` 훅에서 exit 2 를 쓸 때는 **반드시** 이 가드를 넣는다."

### 💡 강조 포인트

> "CLAUDE.md 에 '작업 후 타입체크' 라고 쓰면 **80% 지킨다.**
> 훅에 걸면 **100% 지킨다.** 나머지 20% 가 장애를 만든다."
