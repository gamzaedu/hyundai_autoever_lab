## 💀 자주 나오는 실패

| 실패 | 원인 | 처방 |
| --- | --- | --- |
| Skill 이 호출 안 됨 | `description` 부실 | 4교시 공식 : 무엇을 한다 + 트리거 단어 |
| SubAgent 결과가 뒤엉킴 | 3개에게 같은 파일 수정 지시 | 서브에이전트에게 동시작업을 위임하기 전, 문제되지 않는지 생각하기 |
| Hook 이 세션을 멈춤 | `Stop` 훅 `exit 2` + 루프 가드 없음 | `stop_hook_active` 검사 추가 |
| `null` 에서 화면이 깨짐 | 결측 미처리 | BRIEF §4 결측 현황 먼저 읽기 |
| 시각 계산이 어긋남 | 시스템 시각 사용 | 기준은 **`as_of`** |
