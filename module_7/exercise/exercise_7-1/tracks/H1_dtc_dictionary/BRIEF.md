# H1. 차량 진단코드(DTC) 사전

| 항목 | 내용 |
| --- | --- |
| 문서 버전 | v1.0 |
| 기준 시각 | `2026-03-17T09:00:00+09:00` |
| 난이도 | 하 |

---

## 1. 배경

정비 현장과 관제팀은 차량에서 올라온 DTC 코드를 매번 외부 자료로 찾아 해석한다. 신규 입사자는 코드 체계 자체를 모르는 상태에서 조회를 시작하므로 해석 시간이 길고, 제조사 정의 코드를 표준 코드처럼 단정해 잘못 전달하는 사례가 발생한다.

사내 표준 데이터셋을 기준으로 코드를 조회·해석할 수 있는 단일 화면을 제공한다.

## 2. 사용자

| 구분 | 사용 목적 |
| --- | --- |
| 관제 담당자 | 차량 알람에 포함된 DTC 를 즉시 확인 |
| 정비 지원 | 증상·원인 후보 확인 후 정비소 안내 |
| 신규 입사자 | 코드 체계 학습 |

## 3. 기능 요구사항

| ID | 구분 | 요구사항 | 상세 |
| --- | --- | --- | --- |
| FR-01 | 필수 | 코드 목록 | 60건 전체 표시. 코드 · 계통 · 정의주체 · 제목 · 심각도 노출 |
| FR-02 | 필수 | 코드 검색 | 코드 문자열(부분 일치, 대소문자 무시) 및 제목 한글 검색 |
| FR-03 | 필수 | 계통 필터 | `POWERTRAIN` · `CHASSIS` · `BODY` · `NETWORK` 다중 선택 |
| FR-04 | 필수 | 상세 표시 | 선택 코드의 증상 · 추정 원인 · 비유 · 연관 코드 표시 |
| FR-05 | 선택 | 정의주체 구분 표기 | `MANUFACTURER` 코드는 목록·상세 양쪽에서 시각적으로 구분 |
| FR-06 | 선택 | 심각도 필터 | `CRITICAL` · `WARNING` · `INFO` 선택. 미해설 코드는 별도 취급 |
| FR-07 | 선택 | 연관 코드 이동 | 상세의 연관 코드 클릭 시 해당 코드 상세로 전환 |

### 3.1 표시 규칙

| 규칙 | 내용 |
| --- | --- |
| R-01 | `defined_by` 가 `MANUFACTURER` 인 코드는 `title_ko` · `severity` 가 `null` 이다. "제조사 정의 — 차종·연식별 상이, 정비지침 확인 필요" 로 표기한다. |
| R-02 | `null` 값을 `"null"` · `"undefined"` · 빈 문자열로 출력하지 않는다. |
| R-03 | 코드 체계 해설(1번째 자리 = 계통, 2번째 자리 = 정의주체)은 화면 내에서 확인 가능해야 한다. |
| R-04 | 심각도 표기는 3단계(`CRITICAL` / `WARNING` / `INFO`)를 고정 사용한다. |

## 4. 데이터 명세

### 4.1 파일

| 파일 | 건수 | 설명 |
| --- | --- | --- |
| `data/dtc_codes.json` | 60 | 진단코드 사전 |

### 4.2 `codes[]` 필드

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `code` | string | 진단코드 (예: `P0420`) |
| `system` | enum | `POWERTRAIN` \| `CHASSIS` \| `BODY` \| `NETWORK` |
| `defined_by` | enum | `SAE` \| `MANUFACTURER` |
| `title_ko` | string \| null | 한글 제목. 제조사 정의 코드는 `null` |
| `severity` | enum \| null | `CRITICAL` \| `WARNING` \| `INFO`. 제조사 정의 코드는 `null` |
| `symptoms` | string[] | 증상. 빈 배열 가능 |
| `possible_causes` | string[] | 추정 원인. 빈 배열 가능 |
| `analogy` | string \| null | 비전공자용 비유 |
| `related_codes` | string[] | 연관 코드. 모두 데이터 내 존재 |

### 4.3 분포

| 계통 | 건수 | | 심각도 | 건수 |
| --- | --- | --- | --- | --- |
| `POWERTRAIN` | 42 | | `CRITICAL` | 19 |
| `NETWORK` | 8 | | `WARNING` | 31 |
| `CHASSIS` | 6 | | `INFO` | 5 |
| `BODY` | 4 | | `null` | 5 |

### 4.4 결측 현황

| 항목 | 건수 |
| --- | --- |
| `title_ko` = null | 5 |
| `severity` = null | 5 |
| `symptoms` = 빈 배열 | 5 |

### 4.5 참조 무결성

- `related_codes` 의 모든 값은 `codes[].code` 에 존재한다.
- `systems[].prefix` 는 `code` 첫 글자와 일치한다.
