# H4. 차량 부품 재고 조회

| 항목 | 내용 |
| --- | --- |
| 문서 버전 | v1.0 |
| 기준 시각 | `2026-03-17T09:00:00+09:00` |
| 난이도 | 하 |

---

## 1. 배경

업무차량 정비 시 필요한 부품의 보유 여부를 창고 담당자에게 전화로 확인하고 있다. 차종 호환 여부는 담당자 경험에 의존하며, 안전재고 미만 품목이 발주 시점을 놓치는 경우가 반복된다.

부품 재고를 조회하고 부족 품목을 즉시 식별할 수 있는 화면을 제공한다.

## 2. 사용자

| 구분 | 사용 목적 |
| --- | --- |
| 정비 담당 | 특정 차종에 맞는 부품 보유 여부 확인 |
| 창고 담당 | 안전재고 미만 품목 파악 및 발주 준비 |
| 구매 담당 | 리드타임 · 단가 확인 |

## 3. 기능 요구사항

| ID | 구분 | 요구사항 | 상세 |
| --- | --- | --- | --- |
| FR-01 | 필수 | 부품 목록 | 80건 표시. 품번 · 품명 · 분류 · 재고 · 안전재고 · 창고 노출 |
| FR-02 | 필수 | 통합 검색 | 품번 · 품명 대상 부분 일치 검색 |
| FR-03 | 필수 | 재고 부족 표시 | `stock_qty < safety_stock` 품목을 목록에서 강조 |
| FR-04 | 필수 | 분류 필터 | 9개 카테고리 다중 선택 |
| FR-05 | 선택 | 차종 호환 필터 | 차종 선택 시 해당 차종 호환 부품만 표시 |
| FR-06 | 선택 | 요약 지표 | 총 품목 수 · 부족 품목 수 · 재고 0 품목 수 · 단종 품목 수 |
| FR-07 | 선택 | 정렬 | 재고수량 · 안전재고 대비 부족량 · 단가 기준 정렬 |
| FR-08 | 선택 | 상세 표시 | 호환 차종 목록 · 리드타임 · 최근 입고일 표시 |

### 3.1 판정 규칙

| 규칙 | 내용 |
| --- | --- |
| R-01 | 재고 부족 = `stock_qty < safety_stock`. 같은 값(`==`)은 부족이 아니다. |
| R-02 | 재고 소진 = `stock_qty == 0`. 부족과 별도로 구분 표시한다. |
| R-03 | `discontinued` 가 `true` 인 품목은 단종으로 표기하며, 발주 대상에서 제외 표시한다. |
| R-04 | 부족 판정 임계 로직은 단일 지점에 정의한다. |
| R-05 | 호환 차종은 `compatible_models` 의 `model_id` 를 `models.json` 의 `name` 으로 치환해 표시한다. |

## 4. 데이터 명세

### 4.1 파일

| 파일 | 건수 | 설명 |
| --- | --- | --- |
| `data/parts.json` | 80 | 부품 재고 |
| `data/models.json` | 12 | 차종 마스터 |

### 4.2 `parts[]` 필드

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `part_no` | string | 품번 (`HA-BRA-1013` 형식). 고유 |
| `name_ko` | string | 품명 |
| `category` | enum | `categories[].id` 중 하나 |
| `stock_qty` | number | 현재 재고 수량 |
| `safety_stock` | number | 안전재고 |
| `unit_price_krw` | number \| null | 단가. 견적 미확정 시 `null` |
| `lead_time_days` | number | 발주 리드타임 (일) |
| `warehouse` | string | 보관 창고 |
| `compatible_models` | string[] | 호환 차종 ID 목록 |
| `last_inbound_at` | string \| null | 최근 입고 일시 |
| `discontinued` | boolean | 단종 여부 |

### 4.3 `models[]` 필드

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `model_id` | string | 차종 ID (`MD-01` 형식) |
| `name` | string | 차종명 |
| `powertrain` | enum | `EV` \| `HEV` \| `ICE` |
| `year_from` | number | 출시 연도 |

### 4.4 분포 및 결측 현황

| 항목 | 건수 |
| --- | --- |
| 재고 부족 (`stock_qty < safety_stock`) | 17 |
| 재고 소진 (`stock_qty = 0`) | 3 |
| 단종 (`discontinued = true`) | 12 |
| `unit_price_krw` = null | 4 |
| `last_inbound_at` = null | 4 |

### 4.5 참조 무결성

- `compatible_models` 의 모든 값은 `models[].model_id` 에 존재한다.
- `part_no` 는 80건 전체가 고유하다.
