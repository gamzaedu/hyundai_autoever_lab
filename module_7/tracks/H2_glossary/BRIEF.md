# H2. 신입 온보딩 용어집

| --- | --- |
| 문서 버전 | v1.0 |
| 기준 시각 | `2026-03-17T09:00:00+09:00` |
| 난이도 | 하 |

---

## 1. 배경

커넥티드카 · 관제 · 충전 인프라 도메인은 약어 사용 빈도가 높다. 신규 입사자는 회의와 코드 리뷰에서 등장하는 약어를 그때그때 검색하며, 사내에서 통용되는 의미와 일반 검색 결과가 어긋나는 경우가 있다.

사내 기준 정의를 단일 출처로 제공하는 용어집 화면을 구축한다.

## 2. 사용자

| 구분 | 사용 목적 |
| --- | --- |
| 신규 입사자 | 회의·문서에서 만난 약어 즉시 조회 |
| 교육 담당 | 온보딩 자료의 용어 정의 기준 참조 |
| 개발자 | 코드 · API 필드명의 의미 확인 |

## 3. 기능 요구사항

| ID | 구분 | 요구사항 | 상세 |
| --- | --- | --- | --- |
| FR-01 | 필수 | 용어 목록 | 36건 전체 표시. 용어 · 원어 · 분류 · 정의 노출 |
| FR-02 | 필수 | 통합 검색 | 용어 · 원어(`full_name`) · 별칭(`aliases`) · 정의 본문 대상 부분 일치 검색 |
| FR-03 | 필수 | 분류 필터 | 6개 카테고리 다중 선택. 선택 시 건수 표시 |
| FR-04 | 필수 | 상세 표시 | 정의 · 사용 예시 · 별칭 · 연관 용어 표시 |
| FR-05 | 선택 | 연관 용어 이동 | 연관 용어 클릭 시 해당 용어 상세로 전환 |
| FR-06 | 선택 | 즐겨찾기 | 용어 즐겨찾기 지정 및 즐겨찾기만 보기 |
| FR-07 | 선택 | 검색어 강조 | 목록·상세에서 일치 구간 강조 |

### 3.1 표시 규칙

| 규칙 | 내용 |
| --- | --- |
| R-01 | `example` 이 `null` 인 용어는 예시 영역을 표시하지 않는다. 빈 문자열 또는 "없음" 문구를 출력하지 않는다. |
| R-02 | `aliases` 가 빈 배열이면 별칭 영역을 표시하지 않는다. |
| R-03 | 카테고리 라벨은 `categories[].label` 의 한글 값을 사용한다. `id` 원문을 화면에 노출하지 않는다. |
| R-04 | 검색은 대소문자를 구분하지 않는다. |

| --- | --- | --- |

### 4.2 `terms[]` 필드

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `term_id` | string | 용어 ID (`T-001` 형식) |
| `term` | string | 용어 (약어 또는 한글) |
| `full_name` | string | 원어 전체 표기 |
| `category` | enum | `categories[].id` 중 하나 |
| `definition_ko` | string | 한 문장 정의 |
| `example` | string \| null | 사용 예시 |
| `aliases` | string[] | 별칭. 빈 배열 가능 |
| `related` | string[] | 연관 용어. 값은 `terms[].term` 에 존재 |
