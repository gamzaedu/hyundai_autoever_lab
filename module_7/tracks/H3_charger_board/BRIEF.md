# H3. EV 충전소 현황판

| --- | --- |
| 문서 버전 | v1.0 |
| 기준 시각 | `2026-03-17T09:00:00+09:00` |

## 1. 배경

본사 지하 2층 충전존은 급속 2기 · 완속 6기로 운영되며, 현재 이용 가능 여부를 확인하려면 직접 지하로 내려가야 한다. 고장·점검으로 사용할 수 없는 충전기 정보도 공유되지 않아 헛걸음이 반복된다.

충전존 상태를 한 화면에서 확인할 수 있는 현황판을 제공한다.

## 2. 사용자

| 구분 | 사용 목적 |
| --- | --- |
| 전기차 이용 직원 | 지금 사용 가능한 충전기 확인 |
| 총무팀 | 고장·점검 충전기 파악, 이용 실적 확인 |

## 3. 기능 요구사항

| ID | 구분 | 요구사항 | 상세 |
| --- | --- | --- | --- |
| FR-01 | 필수 | 충전기 보드 | 8기를 카드 또는 그리드로 표시. 충전기 ID · 유형 · 출력 · 존 · 상태 노출 |
| FR-02 | 필수 | 요약 지표 | 사용 가능 / 사용중 / 이용 불가 대수 표시 |
| FR-03 | 필수 | 상태 시각 구분 | 5개 상태를 색상 또는 아이콘으로 구분 |
| FR-04 | 필수 | 필터 | 유형(급속/완속) 및 상태 필터 |
| FR-05 | 선택 | 사용중 상세 | `IN_USE` 충전기의 진행 세션(시작 시각 · 경과 시간 · 시작 SOC) 표시 |
| FR-06 | 선택 | 이용 이력 | 종료 세션 목록. 충전기별 필터 및 최근순 정렬 |
| FR-07 | 선택 | 이용 통계 | 충전기별 누적 충전량(kWh) 및 이용 횟수 |

### 3.1 상태 정의

| status | 한글 라벨 | 이용 가능 |
| --- | --- | --- |
| `AVAILABLE` | 사용 가능 | 가능 |
| `IN_USE` | 사용중 | 불가 |
| `FAULT` | 고장 | 불가 |
| `MAINTENANCE` | 점검중 | 불가 |
| `RESERVED` | 예약됨 | 불가 |

> `RESERVED` 는 상태 값으로 정의만 존재하며 현재 데이터에는 나타나지 않는다.

### 3.2 계산 규칙

| 규칙 | 내용 |
| --- | --- |
| R-01 | 경과 시간은 `as_of` 기준으로 계산한다. 시스템 현재 시각을 사용하지 않는다. |
| R-02 | "이용 불가" 는 `FAULT` + `MAINTENANCE` + `RESERVED` 의 합이다. |
| R-03 | 진행 중 세션은 `ended_at` 이 `null` 인 세션이다. 누적 충전량 집계에서 제외한다. |
| R-04 | 화면에 노출하는 상태 문자열은 §3.1 의 한글 라벨을 사용한다. |

## 4. 데이터 명세

### 4.1 파일

| 파일 | 건수 | 설명 |
| --- | --- | --- |
| `data/chargers.json` | 8 | 충전기 마스터 + 충전존 정보 |
| `data/sessions.json` | 20 | 충전 세션 (진행 4 · 종료 16) |

### 4.2 `chargers[]` 필드

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `charger_id` | string | 충전기 ID (`CH-01` 형식) |
| `type` | enum | `FAST` \| `SLOW` |
| `power_kw` | number | 정격 출력 (급속 100 / 완속 7) |
| `zone` | string | 구역 (`A` · `B` · `C`) |
| `status` | enum | §3.1 참조 |
| `connector` | enum | `DC_COMBO` \| `AC_TYPE2` |
| `current_session_id` | string \| null | 진행 중 세션 ID |
| `last_maintenance` | string | 최근 점검 일시 (ISO 8601) |
| `note` | string \| null | 비고. 고장·점검 사유 |

### 4.3 `sessions[]` 필드

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `session_id` | string | 세션 ID (`S-001` 형식) |
| `charger_id` | string | `chargers[].charger_id` 참조 |
| `plate` | string | 차량 번호 |
| `started_at` | string | 시작 일시 |
| `ended_at` | string \| null | 종료 일시. 진행 중이면 `null` |
| `soc_start_pct` | number | 시작 SOC |
| `soc_end_pct` | number \| null | 종료 SOC. 진행 중이면 `null` |
| `energy_kwh` | number \| null | 충전량. 진행 중이면 `null` |

### 4.4 현재 상태 분포

| 상태 | 대수 |
| --- | --- |
| `IN_USE` | 4 (CH-01 · CH-03 · CH-05 · CH-07) |
| `AVAILABLE` | 2 (CH-02 · CH-06) |
| `FAULT` | 1 (CH-04) |
| `MAINTENANCE` | 1 (CH-08) |

### 4.5 참조 무결성

- `sessions[].charger_id` 는 모두 `chargers[].charger_id` 에 존재한다.
- `IN_USE` 충전기의 `current_session_id` 는 `ended_at` 이 `null` 인 세션을 가리킨다.
