# M3. 스마트팩토리 설비 모니터링

| 항목 | 내용 |
| --- | --- |
| 문서 버전 | v1.0 |
| 기준 시각 | `2026-03-17T09:00:00+09:00` |
| 집계 기간 | 2026-03-10 ~ 2026-03-16 (7일) |
| 난이도 | 중 |

---

## 1. 배경

화성 1공장 3개 라인 12기 설비의 가동 실적은 교대 종료 시 반장이 종이 일지에 기록한 뒤 주 1회 스프레드시트로 취합된다. 가동률 계산 기준이 담당자마다 달라 같은 설비의 수치가 문서마다 다르게 나타나고, 비가동 사유가 집계되지 않아 개선 우선순위를 정하기 어렵다.

교대 실적을 기준으로 설비별 가동률과 이상 설비를 산출하는 모니터링 화면을 구축한다.

## 2. 사용자

| 구분 | 사용 목적 |
| --- | --- |
| 생산관리 | 라인·설비별 가동률 확인, 이상 설비 식별 |
| 설비보전 | 비가동 사유 집계로 정비 우선순위 결정 |
| 품질 | 불량률 이상 교대 확인 |

## 3. 기능 요구사항

| ID | 구분 | 요구사항 | 상세 |
| --- | --- | --- | --- |
| FR-01 | 필수 | 설비 목록 | 12기 표시. 설비명 · 라인 · 공정 · 기간 누적 가동률 · 생산량 노출 |
| FR-02 | 필수 | **가동률 산출** | §3.1 규칙으로 교대 단위 및 기간 누적 가동률 계산 |
| FR-03 | 필수 | 이상 판정 | §3.2 규칙으로 가동률 이상 · 불량률 이상 교대를 판정하고 강조 |
| FR-04 | 필수 | 요약 지표 | 전체 가동률 · 총 생산량 · 총 불량 수 · 이상 설비 수 |
| FR-05 | 필수 | 라인 · 공정 필터 | 라인(L1~L3) 및 공정(6종) 다중 선택 |
| FR-06 | 필수 | 교대 실적 목록 | 선택 설비의 교대별 실적을 날짜순으로 표시 |
| FR-07 | 선택 | 비가동 사유 집계 | 사유별 발생 횟수 및 비가동 시간 합계 |
| FR-08 | 선택 | 일자별 추이 | 설비 또는 라인의 일자별 가동률 추이 표시 |
| FR-09 | 선택 | 교대 비교 | A교대 · B교대 실적 비교 |

### 3.1 가동률 산출 규칙

| ID | 규칙 |
| --- | --- |
| BR-01 | 교대 가동률 = `(planned_min - downtime_min) / planned_min` |
| BR-02 | 기간 누적 가동률 = `Σ(planned_min - downtime_min) / Σ(planned_min)`. **교대별 가동률의 평균이 아니다.** |
| BR-03 | 불량률 = `defect_qty / produced_qty`. `produced_qty` 가 `0` 또는 `null` 이면 산출하지 않는다. |
| BR-04 | 성능 지수 = `produced_qty / 이론 생산량`. 이론 생산량 = `(planned_min - downtime_min) × 60 / rated_cycle_sec` |
| BR-05 | `produced_qty` 가 `null` 인 교대는 **실측 누락**이다. 생산량·불량률 집계에서 제외한다. `0` 으로 치환하지 않는다. 단, 가동률 집계에는 포함한다. |

### 3.2 이상 판정 임계

| ID | 대상 | 임계 |
| --- | --- | --- |
| BR-06 | 교대 가동률 | **85% 미만**이면 이상 |
| BR-07 | 설비 기간 누적 가동률 | **88% 미만**이면 이상 설비 |
| BR-08 | 교대 불량률 | **2.5% 초과**면 이상 |

### 3.3 계산 규칙

| 규칙 | 내용 |
| --- | --- |
| R-01 | 집계 기간은 데이터에 존재하는 7일 전체다. `as_of` 이후 데이터는 존재하지 않는다. |
| R-02 | 공정 · 교대 라벨은 `processes[].label` · `shifts[].label` 의 한글 값을 사용한다. `id` 원문을 화면에 노출하지 않는다. |
| R-03 | 이상 판정 임계값(BR-06~BR-08)은 단일 지점에 정의한다. |
| R-04 | 가동률은 소수 첫째 자리까지 백분율로 표기한다. |

## 4. 데이터 명세

### 4.1 파일

| 파일 | 건수 | 설명 |
| --- | --- | --- |
| `data/machines.json` | 12 | 설비 마스터 + 공장·공정·교대 정의 |
| `data/shift_logs.json` | 168 | 교대 실적 (12기 × 7일 × 2교대) |

### 4.2 `machines[]` 필드

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `machine_id` | string | 설비 ID (`EQ-01` 형식) |
| `name` | string | 설비명 |
| `line` | enum | `L1` \| `L2` \| `L3` |
| `process` | enum | `processes[].id` 중 하나 |
| `rated_cycle_sec` | number | 정격 사이클 타임 (초/개) |
| `installed_at` | string | 설치 일시 |
| `vendor` | string | 제작사 |

### 4.3 `logs[]` 필드

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `log_id` | string | 실적 ID (`SL-0001` 형식) |
| `machine_id` | string | `machines[].machine_id` 참조 |
| `date` | string | 일자 (`YYYY-MM-DD`) |
| `shift` | enum | `A` \| `B` |
| `shift_start` | string | 교대 시작 일시 |
| `planned_min` | number | 계획 시간 (분). 전 교대 480 |
| `downtime_min` | number | 비가동 시간 (분) |
| `produced_qty` | number \| null | 생산 수량. 실측 누락 시 `null` |
| `defect_qty` | number \| null | 불량 수량. `produced_qty` 가 `null` 이면 `null` |
| `stop_reasons` | string[] | 비가동 사유. 빈 배열 가능 |
| `operator` | string | 담당 반 |

### 4.4 설비 구성

| 라인 | 공정 | 설비 | 정격 사이클 |
| --- | --- | --- | --- |
| L1 | 프레스 | EQ-01 · EQ-02 | 12초 |
| L1 | 용접 | EQ-03 · EQ-04 | 26초 |
| L2 | 도장 | EQ-05 · EQ-06 | 95초 |
| L2 | 조립 | EQ-07 · EQ-08 | 41초 |
| L3 | 검사 | EQ-09 · EQ-10 | 18초 |
| L3 | 포장 | EQ-11 · EQ-12 | 9초 |

### 4.5 분포 및 결측 현황

| 항목 | 값 |
| --- | --- |
| `produced_qty` = null (실측 누락) | 9 / 168 |
| `stop_reasons` = 빈 배열 | 39 / 168 |
| 전체 평균 가동률 | 약 93.1% |
| 설비 누적 가동률 최저 | EQ-05 (85.1%) |

**BR-06~BR-08 적용 시 기대값**

| 판정 | 건수 |
| --- | --- |
| 교대 가동률 이상 (< 85%) | **14 교대** |
| 이상 설비 (누적 < 88%) | **2기** — EQ-05 · EQ-06 (도장) |
| 불량률 이상 (> 2.5%) | **14 교대** |

### 4.6 참조 무결성

- `logs[].machine_id` 는 모두 `machines[].machine_id` 에 존재한다.
- `0 <= downtime_min <= planned_min` 을 모든 로그가 만족한다.
- `defect_qty <= produced_qty` 를 모든 유효 로그가 만족한다.
